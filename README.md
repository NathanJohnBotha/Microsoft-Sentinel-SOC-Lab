# Microsoft Sentinel SOC Home Lab

## Overview

This project documents the deployment and configuration of
an Azure-based Security Operations Center (SOC) home lab.

The lab focuses on collecting Windows security telemetry,
monitoring endpoint activity, and investigating suspicious
events using Microsoft Sentinel and Kusto Query Language (KQL).
