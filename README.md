# Microsoft Sentinel SOC Home Lab

## Overview

This project documents the deployment and configuration of
an Azure-based Security Operations Center (SOC) home lab.

The lab focuses on collecting Windows security telemetry,
monitoring endpoint activity, and investigating suspicious
events using Microsoft Sentinel and Kusto Query Language (KQL).

## Technologies Used

- Microsoft Azure
- Microsoft Sentinel
- Azure Log Analytics
- Windows Virtual Machine
- Sysmon
- Azure Monitor Agent (AMA)
- Data Collection Rules (DCR)
- Kusto Query Language (KQL)

## Project Objectives

1. Deploy Azure infrastructure for security monitoring.
2. Configure Microsoft Sentinel and Log Analytics.
3. Deploy and configure a Windows virtual machine.
4. Install Sysmon for endpoint telemetry.
5. Configure Data Collection Rules for log ingestion.
6. Verify Windows Security and Sysmon event collection.
7. Perform security detection and investigation using KQL.
8. Document findings and supporting evidence.
